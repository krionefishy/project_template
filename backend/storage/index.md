# Storage — инфраструктурный слой

## Назначение

Папка `storage/` содержит клиенты для всех внешних хранилищ данных.  
UseCase'ы взаимодействуют через эти клиенты, а не напрямую с библиотеками.

## Компоненты

| Папка | Технология | Назначение |
|-------|-----------|------------|
| `pg/` | PostgreSQL + SQLAlchemy | Основная реляционная БД |
| `redis/` | Redis | Кэш, сессии, refresh-токены |
| `s3/` | S3-совместимое хранилище | Файлы (через Kafka-события) |

## Правила

- **Никаких голых SQL запросов** — только SQLAlchemy ORM и `select()`
- **S3 операции записи/удаления** — только через Kafka (не синхронно в запросе)
- **S3 presigned URL** — синхронно (только чтение, не изменяет данные)
- Клиенты инициализируются один раз в `Application._startup()`
- Dishka регистрирует их с `Scope.APP` — singleton
